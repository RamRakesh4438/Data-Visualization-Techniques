# Data Visualization Techniques using CRISP-DM

## 📌 Project Overview

This project demonstrates the application of the **CRISP-DM (Cross Industry Standard Process for Data Mining)** framework on a real-world healthcare dataset. The experiment focuses on understanding, preprocessing, and visualizing data using Python in Jupyter Notebook/Google Colab.

The notebook follows the complete CRISP-DM workflow, including:

- Business Understanding
- Data Understanding
- Data Preparation
- Data Visualization
- Evaluation
- Deployment

This project is part of the **Data Visualization Techniques** laboratory.

---

## 📂 Dataset

**Dataset Name:** Diabetes 130-US Hospitals for Years 1999–2008

**Domain:** Healthcare

**Records:** 101,766

**Attributes:** 50

The dataset contains patient hospital encounter records and is used to analyze factors related to diabetes patient readmission.
